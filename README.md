# Pygame Temperature Graph Tool

Программа для построения и анализа графиков температуры с возможностью ввода исходных параметров, ручного рисования линий на графике и сохранения результатов в Excel для дальнейшего анализа.

## 📋 Возможности

- Отрисовка координатной сетки по введённым параметрам (температура, время, лимиты).
- Ручное рисование линий на графике с сохранением координат.
- Сохранение данных в Excel-файл (`.xlsx`) с помощью `openpyxl`.
- Загрузка и отображение ранее сохранённых линий.
- Автоматическое построение средней линии по всем сохранённым измерениям.
- Простое управление через поля ввода и кнопки:
  - **Температура** — верхний предел шкалы по вертикали.
  - **Вылет** / **Вылет 2** — горизонтальные красные линии-лимиты.
  - **Время** — длина шкалы по горизонтали (в условных минутах).
  - **Начать** — построение шкал и подготовка графика.
  - **Добавить ТП** — сохранение текущей линии в Excel.
  - **Средняя** — отрисовка усреднённого графика.
  - **Очистить** — сброс состояния.

## 🛠 Технологии

- **Python 3**
- **Pygame** — отрисовка интерфейса и графиков.
- **Pandas** — обработка данных при построении средних линий.
- **NumPy** — математические операции.
- **OpenPyXL** — сохранение данных в Excel.
