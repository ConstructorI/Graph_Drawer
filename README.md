# Графический Интерфейс Graph_Drawer для Рисования Графиков 

Этот проект представляет собой простое приложение на Python с использованием Pygame, позволяющее пользователю визуально создавать графики в заданной области. Оно включает функции ввода параметров, рисования линий мышью, сохранения данных в Excel и отображения среднего значения по сохраненным графикам.

## Возможности

*   **Интерактивное рисование:** Пользователь может рисовать линии в специально отведенной области графика с помощью мыши.
*   **Настройка осей:** Параметры температуры и времени вводятся пользователем для масштабирования вертикальной и горизонтальной осей соответственно.
*   **Поля ввода:** Выделенные поля для ввода температуры, времени и двух предельных значений по оси Y.
*   **Кнопки управления:**
    *   **Начать:** Применяет введенные параметры и рисует сетку графика.
    *   **Добавить ТП:** Сохраняет текущий нарисованный график в файл Excel (`Test<N>.xlsx`, где N - номер сессии).
    *   **Средняя:** Загружает данные из соответствующего Excel-файла и отображает среднюю линию по всем сохраненным графикам (предыдущим запускам с "Добавить ТП") красным цветом.
    *   **Очистить:** Очищает текущий график, сбрасывает состояние приложения и перезапускает основной цикл.
*   **Сохранение данных:** Графики сохраняются в файлы Excel с использованием библиотеки `openpyxl`. Каждая новая сессия (после нажатия "Очистить") создает новый файл.
*   **Отображение сетки:** Горизонтальная и вертикальная сетка рисуются на поле графика в соответствии с введенными параметрами.

## Зависимости

*   Python 3.x
*   Pygame
*   Pandas
*   Numpy
*   Openpyxl

## Установка

1.  Убедитесь, что у вас установлен Python 3.x.
2.  Установите необходимые библиотеки, используя pip:
    ```bash
    pip install pygame pandas numpy openpyxl
    ```

## Использование

1.  Запустите скрипт `main.py`.
2.  Введите желаемые значения в поля "Температура", "Вылет", "Вылет 2" (предельные значения Y) и "Время" (максимальное значение X).
3.  Нажмите кнопку **"Начать"** или клавишу Enter в поле "Время", чтобы отобразить сетку графика.
4.  Кликните и перетаскивайте мышь в области графика, чтобы нарисовать линию.
5.  Используйте кнопку **"Добавить ТП"**, чтобы сохранить текущий график в файл Excel.
6.  Используйте кнопку **"Средняя"**, чтобы отобразить среднюю линию по всем графикам, сохраненным в текущем файле Excel.
7.  Нажмите кнопку **"Очистить"**, чтобы сбросить текущий рисунок и начать заново (новый файл Excel будет создан при следующем сохранении).

## Структура проекта

*   `main.py`: Главный файл приложения, содержащий основную логику и цикл событий.
*   `MainWindow.py`: Класс `MainWindow` для инициализации Pygame, настройки экрана и определения базовых параметров (цвета, шрифты, FPS).
*   `InputBoxesClass.py`: Класс `DrawInputboxes` для создания и управления полями ввода текста.
*   `LinesClass.py`: Класс `DrawLines` для обработки рисования линий, хранения координат и сохранения данных в Excel.
